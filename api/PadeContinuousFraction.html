PadeContinuousFraction(F, xs)¶

padecf.spad line 1 [edit on github]

  • F: Field

  • xs: Symbol

This package computes expansion into continuous C-fraction using Euler-Viskovatov method.

pade_cf2: (Stream F, Stream F, UnivariatePolynomial(xs, F)) -> ContinuedFraction UnivariatePolynomial(xs, F)

pade_cf(f, g, x) produces continuous C-fraction in variable x corresponding to quotient n/d of Taylor series n (d respectively) with coefficients f (g respectively).

pade_cf: (Stream F, UnivariatePolynomial(xs, F)) -> ContinuedFraction UnivariatePolynomial(xs, F)

pade_cf(f, x) produces continuous C-fraction in variable x corresponding to Taylor series with coefficients f.

pade_stream2: (Stream F, Stream F, UnivariatePolynomial(xs, F)) -> Stream UnivariatePolynomial(xs, F)

pade_stream(f, g, x) produces stream of coefficients of continuous C-fraction in variable x corresponding to quotient n/d of Taylor series n (d respectively) with coefficients f (g respectively).

pade_stream: (Stream F, UnivariatePolynomial(xs, F)) -> Stream UnivariatePolynomial(xs, F)

pade_stream(f, x) produces stream of coefficients of continuous C-fraction in variable x corresponding to Taylor series with coefficients f.
