LeafIndexingTree¶

tree.spad line 639 [edit on github]

LeafIndexingTree is a tree where the children of each node are totally ordered from left to right, smaller means left. The root node has an arbitrary label (= value). Each other node has as label the number of leaves in the subtree of its parent node y, consisting of all the childrens left to the edge x-y. These edges are labeled from left to right by 1,2,… Assume that there are exactly l leaves. This setting determines a bijection between {0,1,…,l-1} and the leaves, respectively the paths given as list of edge numbers from the root node to the leaves: rank and unrank. Output is inherited from Tree(NNI) and implemented in the package TreeOutput. See its documentation for more details.

isLeafIndexingTree?: Tree NonNegativeInteger -> Boolean

isLeafIndexingTree?(t) checks, if the given tree is a leaf indexing tree. This has to be checked by inspecting all nodes y, whether either the node is a leaf or if each value of a child x is the number of leaves which can be reached starting from the node via the edges left to the the edge y-x. The value of the root does not play a role, so it can be abitrary.

isPathToLeaf?: (%, List NonNegativeInteger) -> Boolean

isPathToLeaf?(t, ln) checks whether ln is a path from t to a leave of t, in particular two neighboured entries must satisfy a parent-child relationship. Note, that the m leaves are in 1-1-correspondence with such paths, as the graph is a tree. And also with the set {0,..m-1} the ranks.

logicFunctionTree: NonNegativeInteger -> %

logicFunctionTree(n) constructs the tree with depth 2 for all logic function in n variables, represented in canonocial DNF-form as a sum of (s-1) of the 2^n minterms for 1 <= s <= 2^n+1 (children). For each (s-1) at the next level we choose the (t-1)-th (s-1)-subset of the 2^n minterms, for 1 <= t <= binomial(2^n, s). The path from the root to such a leaf is [s,t]. Note, a conversion function pathToLogicFunction is still missing as we need p-restricted integer and a domain LogicFunction not yet in the system. Use with care as there are 2^(2^n) of them.

permutationCyclesTree: (NonNegativeInteger, NonNegativeInteger) -> %

permutationCyclesTree(n, k), abbreviated by [n, k] gives the tree for the permutations of {1,2,..,n} with exactly k cycles. Their number is stirling1(n,k). The constructing recursion is [n,k] = [n-k,k] + (n-1)[n-1,k-1], termination is [n,n] = [(1),(2),..,(n)], [2,1] = [(1,2)] first edge drop cycle (n), if possible, next (n-1) edges: drop n out of the cycle, where i is mapped to n, 1 <= i <= n-1. Bijections: [n-1,k-1] -> [n,k], c1*c2*..*c(k-1) +-> c1*c2*..*c(k-1)*(n) case 1 <= i <= n-1 : [n-1,k] -> [n,k], c1*c2*..*ck +-> _ c1*c2*..*cj'*..*cl where cj=(…i,n,l,,,) is the cycle where i is mapped to n while cj'=(…i,l,,,) is the cycle where n is cancelled.

subsetTree: (NonNegativeInteger, NonNegativeInteger) -> %

subsetTree(n, k) constructs the tree with depth k for all k-subsets of an n-element set as {1,2,..,n}. Its elements are sorted in decreasing order. A path (p1,p2,..,pk) from root to a leave represents the subset {s1 := n-p1+1, s2 := s1-p2+1, …}.

unorderedNumberPartitionTree: (NonNegativeInteger, NonNegativeInteger) -> %

unorderedNumberPartitionTree(n,k), abbreviated by P(n,k), gives the tree forthe unordered number partitions of n in exactly k summands > 0. Therr number can be computed by P(n,k). Recursion is P(n,k) = P(n-k,k) + P(n-1,k-1), Termination is P(n,n) = {[1,1,..,1]}, P(n,1) = {[n]}. First edge -[1,1,,1], if smallest element >= 2, otherwise second edge drop: ..,1]. Bijections: P(n,k,>1) -> P(n-k,k), p +-> p-[1,1,..,1] P(n,k,1) -> P(n-1,k-1), p = [p1,p2,..,.p(k-1),1] +-> [p1,p2,..,.p(k-1)]

unorderedSetPartitionTree: (NonNegativeInteger, NonNegativeInteger) -> %

unorderedSetPartitionTree(n,k), abbreviated by {n,k}, gives the tree for the unordered set partitions of n in exactly k non-empty subsets, a k-clustering. Recursion is {n,k} = {n-1,k-1} + k{n-1,k}, termination is {n,n} = {{1},{2},..,{n}}, {n,1} = {{1,2,..,n}} First edge drop 1-element set {n}, next k edges 2 <= i <= k+1: drop n from the i-th subset where it is included, bijections: {n-1,k-1} -> {n,k}, c = {c1,c2, …, c(k-1)} +-> {c1,c2, …, c(k-1), {n}} case i: {n-1,k) -> {n,k}, c = {c1,c2, …, ck} +-> {c1,c2, …, c(i-1), ci union {n}, c(i+1),..,ck}
